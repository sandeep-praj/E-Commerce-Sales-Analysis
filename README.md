📊 E-Commerce Sales Analysis Project

📌 Project Overview

This project analyzes sales performance data from an e-commerce business to uncover key insights related to revenue,
customer behavior, product performance, and regional sales trends.
Using data analytics techniques and interactive visualizations, the project helps stakeholders make data-driven decisions 
to improve sales performance and business growth.

📈 Key Analysis Performed
1. Sales Performance Analysis
Total Revenue
Monthly Sales Trend
Year-over-Year Growth
Seasonal Sales Patterns

📊 Dashboard Insights
Key Findings

✅ Highest sales were generated from the Technology category.

✅ A small group of products contributed significantly to overall revenue.

✅ Certain regions consistently outperformed others in both sales and profit.

✅ Seasonal spikes were observed during festive and promotional periods.

✅ Repeat customers generated a substantial portion of total revenue.
